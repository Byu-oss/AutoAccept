# Auto-Accept Instagram Follow Requests

## Overview

Both of these scripts automate the process of accepting follow requests on Instagram. 
These scripts includes features such as login, two-factor authentication handling, setting the account to private, and monitoring and accepting new follow requests.

## Configuration

1. **Edit login.ini:**
   - Prior to using these scripts, configure the `login.ini` file with your Instagram account information.

## Basic Process

1. **Login to Instagram:**
   - Execute the script to log in to your Instagram account.

2. **Two-Factor Authentication:**
   - If required, the script handles two-factor authentication seamlessly.

3. **Set Account to Private:**
   - The script ensures that your Instagram account is set to private, for the capability to accept requests.

4. **Monitor Follow Requests:**
   - Regularly monitors incoming follow requests.

5. **Auto-Accept Requests:**
   - Automatically accepts new follow requests based on specified constraints.
